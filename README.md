# Sadia Afroz — academic website

A responsive, static academic website prepared for GitHub Pages. Open `index.html` directly, or preview with `python3 -m http.server 8000` and visit http://localhost:8000.

## Deploy on GitHub Pages

1. Create a repository named `SadiaAfroz.github.io` in the `SadiaAfroz` GitHub account for a site at `https://SadiaAfroz.github.io/`. You can also use any repository name for a project site.
2. Upload this folder's contents, including `index.html`, `assets/`, `files/`, and `.nojekyll`, to the repository's `main` branch. Upload the contents, rather than a containing folder.
3. In the repository, open **Settings → Pages**. Under **Build and deployment**, select **Deploy from a branch**, then **main** and **/ (root)**, and save.
4. GitHub shows the published address on that page once deployment finishes.

No build step, package installation, external fonts, or third-party JavaScript is required. Relative file paths support both account and project Pages sites.

## Editing

- `index.html`: profile, experience, publications, projects, skills, and awards.
- `assets/style.css`: colors, typography, and responsive layout.
- `assets/site.js`: mobile navigation and footer year.
- `files/Sadia_Afroz_CV.pdf`: downloadable résumé.
- `assets/publications.json`: a reference copy of the 16 publication records. The website renders the publications directly in HTML; edit the HTML to change the visible list.

Content and links were transcribed from the supplied comprehensive CV. A typographic initials avatar is used because no portrait was supplied. The public contact section uses the professional email; the phone number is available in the downloadable CV.

The academic structure follows the supplied Aminul Islam website example. This version uses newly written HTML/CSS/JS and excludes the example author's personal content, documents, analytics, and administration scripts.
